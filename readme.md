
# PoC GitHub Security Rules

Este repositorio contiene la Prueba de Concepto para la implementación de reglas de seguridad y compliance en GitHub.

## Objetivos

- Implementar reglas de protección de ramas.
- Configurar revisiones obligatorias de Pull Requests.
- Incorporar flujos de CI/CD con validaciones de seguridad.
- Implementar GitHub Advanced Security (CodeQL y Secret Scanning).

## Estructura del repositorio

- `.github/workflows/` : Pipelines de CI/CD automatizados.
- `docs/` : Documentación técnica y política de compliance.
- `src/` : Código fuente de la aplicación.
- `tests/` : Pruebas automatizadas.
