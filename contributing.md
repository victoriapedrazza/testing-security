# Guía para Contribuir

Gracias por tu interés en contribuir a este proyecto.

## Normas Básicas

- Trabaja siempre en branches para desarrollar features o fixes.
- Asegúrate que tu código pase todas las pruebas.
- Sigue las políticas de seguridad y compliance.
- Usa las plantillas de issues y pull requests.
- Incluye pruebas para tus cambios.

## Proceso de Pull Request

- Abre un Pull Request describiendo tus cambios.
- Solicita revisiones de al menos 2 miembros asignados.
- No merges sin aprobación.
